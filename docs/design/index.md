# Design documents

Accepted designs for non-trivial changes, numbered in order of acceptance. Each records the problem, the options considered, the decision and its status. Proposals start as a pull request adding a new numbered file here; see [Contributing](https://github.com/GoogleCloudPlatform/k8s-aibom/blob/main/CONTRIBUTING.md).
