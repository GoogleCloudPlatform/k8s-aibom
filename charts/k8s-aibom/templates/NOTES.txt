k8s-aibom is installed in the {{ .Release.Namespace }} namespace.

By default nothing is inventoried until a namespace opts in with a label:

  kubectl label namespace <namespace> aibom.k8saibom.dev/enabled=true

See the results:

  kubectl get aibom -A
  kubectl aibom summary -A   # kubectl plugin: kubectl krew install aibom

Sinks and discovery settings (including a namespaceSelector, which replaces
the label) are set through this chart's config.* values and end up on the
AIBOMControllerConfig named "default". Sinks that read credentials from a
Secret also need --set rbac.sinkSecretAccess=true (off by default).

Docs: https://github.com/GoogleCloudPlatform/k8s-aibom#readme
